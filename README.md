# bogo-frontend-task
Frontend technical support task – BOGO UI.

This is a single-page demo implementation created using vanilla HTML, CSS, and JavaScript
as part of a Frontend Technical Support interview assignment.

## Features
- Pixel-accurate UI based on the provided Figma design
- Interactive unit selection
- Dynamic total price update
- Add-to-cart confirmation message

## Tech Stack
- HTML
- CSS
- Vanilla JavaScript
